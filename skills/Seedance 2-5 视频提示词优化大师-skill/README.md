# seedance2-5-master-prompt · Seedance 2.5 视频提示词优化大师

一款专为 **Seedance 2.5** 量身打造的视频提示词 Skill。<br>
**把一句想法 / 碎片主题 / 小说片段，变成一支高级的 4–30 秒多镜头视频。**

---

## 写 Seedance 2.5 视频提示词，先弄明白这几点：

1. **主体、场景、音乐、镜头要写清楚**：
   - **主体**：有参考图时指明具体是哪张（`@图片1 是主角1`），名字贯穿始终；无图时先写完整外观档案；
   - **场景**：有图用 @ 引用，无图写完整场景锚点；
   - **音乐**：默认配 BGM（`音乐：根据画面氛围生成匹配的背景音乐与对应音效`），仅当用户明确说不要 BGM 时才改为"只生成音效"；
   - **镜头**：镜号一定写清楚（镜头1、镜头2…），时间戳视内容情况而定。

2. **不用盲目追求分辨率**：720P 对提示词遵循最好，1080P 次之，4K 一般。

3. **核心依然是画面控制**：脑里要有具体的分镜、画面、转场、动作、运镜和剧情细节，有好的画面才有好的故事。

把这些认知固化成规则、模板、质检清单后，于是有了这个 Skill。**给它一段文本——小说片段、一句剧情、几个主题词——它给你一条可直接复制进 Seedance 2.5 的多镜头提示词**，并按你的资产情况（有图用 @ 引用、无图先写档案、需出图再给 T2I）附上对应的资产写法。

## ✨ 它能做什么

### 🎬 直出 Seedance 2.5 多镜头提示词

| 输入类型 | 处理方式 |
|---------|---------|
| 小说 / 剧本 / 脚本片段 | 提炼最具画面感的故事节奏，拆成连续镜头 |
| 一句简短剧情 | 补全前因后果与转折，再拆镜头 |
| 几个主题词 | 创意扩写出「起承转合」短片，再拆镜头 |

不管输入是什么，输出永远是同一种结构：**【脚本总览】+【资产说明】+【视频提示词（单一完整可复制块）】**。其中【资产说明】按你的资产情况自动切换写法：有图→@引用、无图→完整档案、需出图→再附 T2I。**视频提示词把总时长、主体档案、场景锚点、音乐、镜头全部并成一个块，可直接整块复制。**

### 🎯 默认产出

- **总时长 4–30s**（默认推荐 15–30s，上限 30s，超过自动收敛）
- **镜头数由故事节奏决定**，无固定档位（30s 通常落在 8–14 镜）
- **每镜标注时间区间**，各镜时长之和严格等于总时长
- **按资产情况自动切换写法**：有图片资产 → `@图片N 主体短名` 显式引用；无图片资产 → 先写完整主体档案/场景锚点；需先生成资产图 → 附 T2I 提示词
- **支持多模态资产**：图片（锁外观）/ 视频（参考运镜/动作）/ 音频（配乐/音色），三者可叠加 @ 引用

### 📐 Skill 工作流

1. **解析与扩写**：拆故事节奏、清点主体与场景、定基调（含真人感设定）、**确认资产情况**
2. **定时长与镜头数**：按故事节拍排镜，每镜按类型给时长，加总校准
3. **建立主体与场景档案**：写锚点描述、取资产短名，锁定全片一致性
4. **资产处理**：有图片→@引用；无图片→写完整档案；需出图→附 T2I 提示词；有视频/音频→@引用
5. **写多镜头视频提示词**：严格套统一模板，只写会动的画面
6. **控制总字数**：硬约束 ≤4000 字
7. **交付前质检**：逐项核对（含违禁词过滤、推荐风格），不过关不出门

## 🛠️ 设计哲学

### 1. 资产锚定：一致性的根本解法

维系一致性的本能反应是「每镜反复写主角外观」——这恰恰是错的：越复述，模型注意力越被占用，动作与运镜越弱。

**解法**：先确认用户资产情况——
- **有图片资产**：主体/场景用 `@图片N 主体短名` 显式引用，固定外观交给图去锁；
- **无图片资产**：先写完整主体档案/场景锚点（作为模型认知来源），正文只用**短名 + 本镜变化点**，不复述「约30岁壮汉、浓眉方脸…」；
- 需先生成资产图：再附 T2I 提示词。

提示词只负责「动」，一致性交给资产图或档案去锁。

### 2. 按故事类型配置镜头

很多人先定「我要 12 镜」再用总时长÷12，结果通篇 2.5s 快切、毫无起伏——这就是狂切。

**硬规则**：镜头数是排完故事节拍、给每镜选好类型后算出来的结果，不是先定的指标。每镜时长按类型定：**特写/快切 2-3s、中景/叙事 3-6s、全景/建立 6-7s**。每次切镜必须有叙事理由（换空间/时间/视角/信息层级/情绪断点），能一镜说完的不切两镜，长短交替，快剪成组后用长镜收住。

典型 30s 骨架：`全景建立(6-7s) → 中景叙事×2-3 → 特写快剪组(2-3s)×3-4 → 中景过渡 → 全景收尾`

### 3. 纯写画面，不干扰模型

```
❌ 静帧式：侠客站在山路上，夕阳余晖洒在身后，目光锐利
✅ 视频式：侠客大步从画面深处走来，长袍下摆被风向后吹起，镜头从地面缓慢上摇至全景，夕阳从山脊缓缓下沉
```

镜头正文只写「摄影机拍到了什么、怎么动」——不写音效（交由头部固定音乐行）、不写 `剧情：…`、不写情绪解释。
**视频化三要素**（每镜自检，缺一重写）：① 强动词 ② 镜头运动词 ③ 环境/光线动态。

### 4. 统一提示词模板（单一完整可复制块）

```
【Seedance 2.5 分镜提示词】总时长 <N>s，<风格，仅用户要求时写>，<画幅>

【主体】
- @图片1 主角1（有图）｜ 或 主角1：<完整外观>（无图）

【场景】
- @图片4 市集（有图）｜ 或 市集：<完整场景>（无图）

主体：@图片1 主角1、@图片2 主角2（或短名）
场景：@图片4 市集（或场景短名）
参考：@视频1 运镜参考、@音频1 配乐参考（可选）
音乐：根据画面氛围生成匹配的背景音乐与对应音效
镜头1 ｜ 0.0–6.0s ｜ …
镜头2 ｜ 6.0–9.5s ｜ …
```

- **音乐行默认配 BGM**（全片唯一声音指令，各镜不再描述音效）；仅当用户明确不要 BGM 时改为"不要生成任何背景音乐，只生成对应音效"。
- **对白必须写入镜头正文**（标注"对白口型同步"），原文台词一字不漏。
- **默认不擅自指定风格**：有资产时风格由资产决定，仅用户要求换/推荐/指定风格时才写，且只在镜头1点明一次；用户未指定时可推荐 1-3 种供选择（确认后才写）。
- **有视频/音频资产**：头部 `参考：` 行加 `@视频N` / `@音频N`。
- **硬约束**：各镜时长之和 = 总时长 ≤ 30s；输出总字数 ≤ 4000 字。超字数优先压重复环境/风格描述、合并次要镜头，**不靠删运镜省字**。

## 📌 官方手册对齐（2026-07-31 更新）

本 Skill 已对齐《小云雀 Seedance 2.5 使用手册》的核心规则，并补充进 SKILL.md：

- **时间戳三类写法**：时间区间（须连续、禁断层）/ 时间点控制 / 相对时间控制
- **反过度**：时间段内剧情过少→模型自由发挥、过多→过度剪切；不用时间戳控频率
- **真人感设定**：写实风格主动保留不完美细节，负向排除 AI 油亮皮肤/塑料感/蜡像感
- **动作概括优先 + 表情描述化**：能概括先概括、只写记忆点细节；表情用描述性语句减少成语

## 🆕 本轮能力更新（2026-08-03）

- **对白规则**：原文对白必须完整写入镜头正文 + 标注"对白口型同步"，一字不漏（对白属画面内容，不受音乐行限制）
- **BGM 放开**：音乐行默认配 BGM，仅用户明确说"不要 BGM/纯音效"时才改为"只生成音效"
- **资产模式重构**：先确认资产情况——有图 → `@图片N 主体短名` 引用；无图 → 先写完整档案；需出图 → 附 T2I。不再默认每次必给 T2I
- **多模态资产**：图片（锁外观）/ 视频（`@视频N` 参考运镜动作）/ 音频（`@音频N` 配乐音色），三者可叠加
- **单一完整复制块**：总时长、主体档案、场景锚点、音乐、镜头并成一个提示词块，整块复制
- **默认不擅自指定风格**：仅用户要求换/推荐/指定风格时才写（且只在镜头1点明一次）；未指定时可推荐 1-3 种供选择
- **违禁词自动替换**：血腥暴力 / 低俗 / 色情性暗示三类命中即替换为中性词，确保提示词无违禁词（乱伦/恋童/兽交为绝对违规词）
- **推荐风格质检动作**：用户未指定风格时，交付时推荐 1-3 种贴合故事气质的风格供其选择（推荐 ≠ 擅自写入，确认后才写）
- **双模式对照模板**：templates.md 提供"有资产 A / 无资产 B"两个完整可复制块 + 差异速查表，任何使用者照抄对应模板即可保证"有无资产"写法一致

## 🚀 快速开始

### 适用对象

适用于任何支持 `Agent Skills` 规范的 AI Agent。只要你的 Agent 能读取并遵循 Skill 指令，就能用它设计 Seedance 2.5 视频提示词。推荐推理能力较强的模型（如 Claude Opus 5、DeepSeek-v4-pro 等）。

### 使用

安装后，在对话中用以下任意方式触发即可：

- "帮我把这段小说做成 Seedance 视频分镜"
- "用 seedance2-5-master-prompt skill，设计一个 30 秒的多镜头提示词，主题是……"
- "做个 shotlist，图生视频"

触发关键词：`seedance 视频提示词`、`多镜头提示词`、`视频分镜脚本`、`镜头脚本`、`shotlist`、`文生视频 / 图生视频`、`AI 视频镜头脚本`。

### 推荐工作流

```
情况 1 · 用户有图片资产：
  直接用 @图片N 锚定主体/场景 → 把视频提示词 + @图片 资产一起喂给 Seedance 2.5

情况 2 · 用户无图片资产：
  直接文生视频 → 用 Skill 输出的「完整主体档案/场景锚点 + 视频提示词」

情况 3 · 无图但需先生成资产图：
  ① 先用 Skill 输出的「资产图 T2I 提示词」在文生图模型生成主体/场景图
  ② 把生成的图作为 @图片 资产，连同「视频提示词」一起喂给 Seedance 2.5
```
