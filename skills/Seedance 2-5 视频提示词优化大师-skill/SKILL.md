# seedance2-5-master-prompt skill：Seedance 2.5 视频提示词优化大师

把用户输入的文本设计成 **4-30s 的连续镜头脚本**，并输出为**一条**可直接复制进 Seedance 2.5 模型的多镜头视频提示词：头部锚定主体、场景、音乐，正文按 `镜头N ｜ …` 顺序排列。默认推荐 15-30s，时长未明确时先与用户确认。

## 默认前提（硬性）

- **先确认资产，再决定是否写文生图**：主体与场景都是视频的"资产图"。**先询问用户是否已有图片/视频资产**——①已有（用户提供图片/视频）→ 直接用资产短名锚定，**不写文生图(T2I)提示词**，头部 `主体：`/`场景：` 填资产名即可；②没有 → 才设计**文生图(T2I)提示词**（见第 4 步）供先生成资产图。**不要默认每次必给 T2I 提示词**。
- **音乐行默认配 BGM**：`音乐：根据画面氛围生成匹配的背景音乐与对应音效`。这是全片唯一的声音指令——**各镜头里不再描述任何音效**，音效与配乐交由模型根据画面自动匹配。**仅当用户明确说"不要 BGM/不要背景音乐/纯音效"时**，才改为 `音乐：不要生成任何背景音乐，只生成对应音效`。
- **镜头正文只描述画面**：不写音效，不写剧情作用/叙事目的。叙事在设计阶段想清楚，但不落进提示词。
- **对白必须写入镜头正文**：原文含人物台词/对白时，必须完整写入对应镜头正文，并标注"（对白口型同步）"。对白属于画面内容（口型），不是音效，不受"音乐行"限制；原文对白一字不漏。
- **默认客观写分镜，不擅自指定风格**：你的核心职责是写好分镜结构与提示词。用户有资产时，风格由资产决定；**默认不写风格关键词**，仅在用户要求换风格/推荐风格/指定风格时才给出。**用户未指定风格时，可在交付时推荐 1-3 种贴合故事气质的风格供其选择**（推荐不等于写入提示词，用户确认后才写）。
- **违禁词自动替换**：输出前自动过滤违禁词（血腥暴力/低俗/色情性暗示三类），命中即替换为相近中性词，确保最终提示词不含违禁词（违禁词表见硬约束#9 与 templates.md 速查表）。
- 默认用中文写提示词。用户要求或目标为海外工具时给英文/中英双语。

## 能力边界

- 输入三类，分别处理：①小说/剧情/脚本片段→提炼最具画面感的故事节奏；②一句简短剧情→补全前因后果与转折；③几个主题词→创意扩写出"起承转合"短片创意，再拆镜头。
- 输出必须明确：​**总时长（范围 4-30s，默认推荐 15-30s，上限 30s）**、**镜头数（按内容定，无固定档位）**、每镜时间区间。
- 用户显式指定时长/镜头数则优先；时长未明确时，先向用户确认或给出 15-30s 推荐；超过 30s 时按 30s 处理并一句话说明。

## 工作流程（严格按序执行）

### 第 1 步 · 解析与扩写输入

在心里列出并补全：

1. **故事节奏：​**拆成有先后、连续性、逻辑紧密的故事画面。故事节奏是你的设计依据，写进【脚本总览】即可，不写进视频提示词。
2. **主体**：有几个角色/物体/道具主体？各自外观线索（缺失则合理设定）。**同时确认用户是否已有资产图**（决定第 4 步写法）。
3. **场景**：地点、时间、天气、空间。跨场景时列清场景数量与切换点。
4. **基调/类型**：从故事气质推断（科幻/悬疑/温情/热血/广告/武侠…）。
5. **真人感设定（若风格为写实/纪实/口播/宠物/生活化）**：主动规划"不完美细节"——细纹、毛孔、皮肤轻微不对称、手部瑕疵、衣物褶皱、真实环境光、自然动作。目标画面越接近实拍，越要在这一步想清楚：自然窗光、轻微手持、浅景深、真实皮肤纹理、材质瑕疵、环境杂乱度。**降低 AI 感的写法**：不要同时要求过度美颜、完美对称、超干净棚拍、过强磨皮；可在负向/禁止里明确"不要 AI 油亮皮肤、不要塑料感、不要蜡像感"。真实感往往来自"不那么完美"的细节，这是设计阶段的默认考量。

### 第 2 步 · 定总时长与镜头数（由故事和节奏决定）

**镜头数完全取决于故事和节奏**，没有固定档位，也没有数量上限。流程是：定总时长 → 排叙事节拍 → 给每个节拍选镜头类型 → 按类型给时长 → 加总校准。​**不要用"总时长 ÷ 平均值"倒推镜头数。，**

- 总时长：**范围 4-30s，默认推荐 15-30s**；内容简单取 15-20s，叙事完整取 25-30s。时长未明确时先向用户确认或给出推荐，再据此排镜；用户另有要求时，则听用户。
- **每镜时长按镜头类型定**（核心依据）：

| 镜头类型 | 时长 |
| - | - |
| 特写 / 快节奏镜头 | 2-3s |
| 中景 / 叙事镜头 | 3-6s |
| 全景 / 固定镜头 | 6-7s |

- **镜头数是上面选择的结果**。参考量级：30s 视频通常落在 **8-14 镜**（均值约 2-4s）；20s 约 7-10 镜；15s 约 4-7 镜；10s 以内约 2-4 镜。全景、固定镜头多则镜头数偏少，特写快切多则偏多。镜头的数量主要取决于**故事**和**节奏**。

**反狂切镜头规则**（约束的是"无理由地切"，不是"短镜头"）：

1. **每一次切镜都要有叙事理由**——换空间、换时间、换视角、换信息层级、情绪断点。为炫技而切、为"看起来热闹"而切，一律合并。这是唯一真正的反狂切标准。
2. **能一镜说完的不切两镜**：优先用「运镜 + 主体动作 + 环境变化」在一镜内完成推进（推近代替切特写、跟拍代替切两个机位）。
3. **分镜节奏要有起伏，不能通篇同一时长**：全篇都是 2-3s 就是狂切，全篇都是 6s 则拖沓。长短交替，让快剪段落成为对比出来的高潮。
4. **快剪成组使用**：连续 2-3s 的短镜适合表现打斗、蒙太奇、情绪爆点，成组出现后要用一个中景或全景把节奏收住。
5. 长镜头是优点：建立镜可用 6-7s，靠运镜与动作分层填满，不必急着切。

**时长算术（唯一硬约束）**：各镜时长之和 = 总时长，且总时长 ≤ 30s。每镜标明时间区间（如 `0.0–6.5s`），自检末镜结束时间 = 总时长。
**节奏规则**：开场用全景/建立镜（6-7s）交代环境与主体 → 中段用中景叙事镜稳步推进 → 高潮切入 2-3s 特写快剪组 → 结尾回到较长镜头收束（≥3s）。

**时间戳写法（三类，按需选用，默认第 1 类）**：
1. **明确时间区间**（推荐）：每镜标连续区间，如 `0.0–6.5s` / `6.5–9.5s`。**时间轴必须连续**，禁止出现"0-3秒…5-6秒…"这类断层表达。
2. **时间点控制**：在指定秒发生指定事，如"第 5s 快速向左横移转场""第 2 秒一道金雷自画面顶部破空直落"。
3. **相对时间控制**：以相对表述交代先后，如"张三呆滞站在原地，3 秒后周围人纷纷摇头""主角按下快门后画面定格 1 秒"。

**反过度（时长/内容配比约束）**：
- 指定时间段内**剧情过少** → 模型会自由发挥补足（结果不可控）；**内容过多** → 会导致过度剪切或剧情遗漏。每镜信息量与时长必须匹配，不要在一镜里塞多个关键事件。
- **不建议用时间戳控制频率/频次**（如"一秒摇头 3 次"），模型做不出精确频次，只写动作本身。

### 第 3 步 · 建立主体与场景档案（一致性核心）

1. 为**每个主体**写**锚点描述**——固定不变的视觉特征：年龄、发型发色、瞳色、脸型、服装/材质、标志性道具。措辞一旦确定，全程不改。
2. 为**核心场景**写场景锚点（地点、时间、光线色调、天气、空间布局）；同场景全程沿用同一措辞。
3. 给每个主体/场景取一个**短名（资产名）**，如「侠客」「猛兽」「荒山古道」。头部 `主体：`/`场景：` 只填这些短名，镜头正文也只用短名。
4. **多主体**：列出人物关系与出场顺序；每镜标注在场主体。
5. **风格（默认不指定，按需才写）**：**默认不写风格关键词**——尤其用户已有资产时，风格由资产图/参考素材本身决定，不需要文字指定；客观写好分镜与提示词即可。**仅当用户明确要求"换风格/推荐风格/指定某种风格"时**，才给出全片统一的风格关键词，并只在镜头1点明一次、后续不重复。
6. 锚点档案是**资产图生成依据**，**不在各镜头里逐字复述**（原因见第 5 步）。

### 第 4 步 · 资产处理（先确认资产，再决定写法）

**先确认用户有哪些资产**（可放在第 1 步解析时一起问）。Seedance 2.5 支持**三类多模态资产**，均可通过 `@` 引用：

| 资产类型 | 用途 | @ 写法示例 |
|---------|------|-----------|
| **图片**（@图片N） | 锁定主体/场景外观、首尾帧 | `@图片1 是主角1`、`@图片1 作为首帧` |
| **视频**（@视频N） | 参考运镜/动作/节奏/特效 | `参考@视频1 的运镜`、`@视频1 是动作参考` |
| **音频**（@音频N） | 配乐/音效/对白音色参考 | `@音频1 用于配乐`、`旁白音色参考@音频1` |

**关键判断——有/无图片资产**（决定主体场景写法）：

#### 情况 A：用户有图片资产（锁定主体/场景外观）
- **不写 T2I 提示词**，跳过文生图。
- **分镜正文显式用 @ 引用**：把图片资产与角色/场景对应起来，写法为 `@图片1 是主角1`。每个主体/场景**首次出现时**用 `@图片N 是 主体短名` 声明对应，后续正文用短名 + `@图片N` 指代。
- 主体档案/场景锚点：从简（有图锁定外观，只列短名与关键变化点即可）。
- 示例写法：`镜头1 ｜ @图片1 主角1蹲在泥地上作画 …`

#### 情况 B：用户无图片资产（文生视频）
- **先写主体档案 + 场景锚点（完整版）**：因无图，要靠文字立起角色与场景——每个主体写全外观（年龄/发型/五官/服装材质/标志道具），每个场景写全（地点/时间/光线色调/天气/空间布局）。这是模型的角色认知来源，必须完整。
- **分镜正文用短名指代**：档案已完整定义角色，正文只用短名（如「马良」）+ 本镜变化点，**不必重复长篇外观**。
- 可选：如需先生成资产图，可额外给 T2I 提示词；若直接文生视频，则给出完整主体档案/场景锚点即可。
- 主体资产/场景资产（若给 T2I）：主体背景简洁（纯色/白底/浅景深虚化）、只突出主体、不带叙事场景；内容 = 逐字复述锚点 + 姿态/角度 + 统一风格 + 画质词（8K、精致细节、studio 柔光）。场景展示代表性全貌、排除人物与临时道具、光线色调布局与锚点一致。数量精简，不凑数。

#### 视频 / 音频资产（与图片无关，始终按需引用）
- **有视频参考**：在对应镜头或头部注明 `参考@视频N 的运镜/动作/节奏`。用于复刻运镜、动作、转场、卡点。
- **有音频资产**：在头部或声音处注明 `@音频N 用于配乐 / 音色参考 / 对白参考`。
- 视频/音频**不替代图片**的功能——图片锁外观，视频锁动作，音频锁声音，三者可叠加。

### 第 5 步 · 写多镜头视频提示词（只写画面，且是会动的画面）

**两条核心原则：、**

- **只描述画面**：镜头正文写的是"摄影机拍到了什么、怎么动的"，重点是介绍视频的画面内容。不写音效，不写"剧情：本镜推进了什么"，不写情绪解释与叙事意图。
- **是视频不是静帧**：每镜是一段会动的视频片段，禁止写成静态画面 caption。

严格按统一模板（见"输出格式"）。每个 `镜头N` 一行，必须含以下要素：

- **时间区间**（写在镜号后）
- **场景短名**（多场景时每镜标明当前场景；单场景可在镜头1标明后省略）
- **主体**（按第 4 步的资产情况二选一）：
  - **有资产**：用 `@图片N 主体短名` 引用（如 `@图片1 主角1`），首次出现时声明对应关系，后续用短名 + 本镜变化点。
  - **无资产**：用**短名 + 本镜变化点**（如「马良」蹲下、抬头），外观已在第 4 步的完整主体档案中定义，正文不复述。
  - 两种情况都**不逐字复述固定外观**——有图靠 @ 锁定、无图靠档案定义，重复描写会抢占模型注意力、弱化动作与运镜。
- **景别 + 镜头运动**：明示方向与速度（缓慢推近 / 拉远 / 上摇 / 横移 / 跟拍 / 环绕 / 手持轻晃 / 慢动作 / POV）。景别要与第 2 步定的时长匹配。6-7s 的建立镜必须写出运镜的**阶段变化**（如"先低角度缓推，至中段上摇至全景"）；2-3s 的特写只给一个明确、干净的运镜，别塞复杂运动。
- **动作过程**：强动词写出本镜内的连续动作变化（"步伐由快转慢→缓缓抬头→眉头微皱"）。3s 以上的镜头至少写 2 个递进动作；2-3s 的短镜只写 1 个动作到位，写多了模型做不完。
- **动作概括优先**：能概括的动作先概括（"连续做了几组高抬腿和空翻""双方展开近身搏斗"），**只在少数有记忆点的动作上写具体细节**，不要为显得专业而逐帧编舞，也不要重复写相同动作。
- **表情用描述性语句**：减少成语，把抽象情绪写成可拍细节（"津津有味地吃饭"→"脸上带着满足的笑容，大口地吃饭"）。
- **时间内变化**：光线、衣物飘动、落叶飞舞、表情转换、色温过渡…
- **构图**：主体位置、前后景。
- **参考资产引用（如用户有视频/音频）**：某镜需参考指定视频/音频时，在本镜标注 `参考@视频N 的运镜` / `@音频N 音色` 等；或整条统一在头部说明。

**每镜写完自检（视频化三要素，缺一重写）**：① 至少 1 个强动词；② 至少 1 个镜头运动词；③ 至少 1 个环境/光线动态。

❌ 静帧式（错）：「侠客站在山路上，夕阳余晖洒在身后，目光锐利」
❌ 夹叙事/音效（错）：「…夕阳从山脊缓缓下沉；音效：碎石脚步、山风。剧情：醉态登场，为猛兽出场铺垫」
✅ 纯画面视频式（对）：「侠客大步从画面深处走来，长袍下摆被风向后吹起，镜头从地面缓慢上摇至全景，夕阳从山脊缓缓下沉」

镜头之间要有**景别/机位/情绪的变化与剧情递进**，不要每镜雷同——但递进靠画面本身呈现，不靠文字解说；变化靠设计，不靠多切。

### 第 6 步 · 控制总字数（硬约束 ≤4000 字）

- 全部输出（如含 T2I 提示词则计入，多镜头视频提示词）**总字数 ≤ 4000 字**。
- 预算：每镜约 `3000 ÷ 镜头数` 字；如写 T2I 提示词，资产部分 ≤1000 字。
- 若超字数：优先压缩重复的环境/风格描述，合并次要镜头（顺便改善节奏），不要靠删运镜或动作过程来省字。

### 第 7 步 · 交付前质检（逐项核对）

- [ ] 已明确总时长（范围 4-30s，默认推荐 15-30s，≤30s）与镜头数，各镜时长之和 = 总时长。
- [ ] 每镜时长与其镜头类型匹配（特写/快切 1-3s，中景/叙事 3-5s，全景/固定镜头/长镜头 5-7s）。
- [ ] 镜头数由故事节奏推出，不是拿平均值除出来的。
- [ ] 时长有起伏，不是通篇同一节奏；快剪组后有较长镜头收住；每次切镜都有叙事理由。
- [ ] 已确认资产情况：**有图片 → 分镜正文用 `@图片N 主体短名` 显式引用**（首次声明对应，后续短名指代），不写 T2I；**无图片 → 先写完整主体档案/场景锚点**，分镜正文用短名指代（如给 T2I，主体干净背景、场景排除人物，措辞与锚点一致）。
- [ ] 用户有视频/音频资产时，已在头部「参考」行或对应镜头标注 `@视频N` / `@音频N` 引用。
- [ ] 视频提示词严格按统一模板：`主体：` / `场景：` / `音乐：根据画面氛围生成匹配的背景音乐与对应音效`（用户明确不要 BGM 时用"不要生成任何背景音乐，只生成对应音效"）/ `镜头N ｜ …`。
- [ ] 头部主体、场景填的是资产短名，镜头正文也只用短名 + 变化点，不逐字复述固定外观。
- [ ] 镜头正文**只有画面**：无音效描述、无 `剧情：…`。
- [ ] 原文含对白时，已完整写入对应镜头正文并标注口型同步，一字不漏。
- [ ] 每镜含强动词 + 镜头运动 + 环境/光线动态，无任何一镜读起来像静帧。
- [ ] 多主体已注明关系与出场顺序，每镜标了在场主体；多场景每镜标了场景。
- [ ] 风格：默认未擅自指定（有资产时风格由资产决定）；仅当用户要求时才给出统一风格关键词，且只在镜头1点明一次。
- [ ] **如用户未指定风格，已在交付时推荐 1-3 种贴合故事气质的风格**（供用户选择；推荐不等于擅自写入提示词，最终由用户确认后才写）。
- [ ] 输出总字数 ≤ 4000 字。

## 输出格式

按 `references/templates.md` 输出，含完整范例与风格/运镜/光线词库速查。结构：

1. **【脚本总览】**：总时长 / 镜头数 / 镜头数理由（节拍如何对应镜头类型）/ 节奏骨架（各镜类型与时长序列）/ 主体档案 / 场景锚点。叙事与镜头规划的说明**只写在这里**；资产情况（已有/需生成）在此注明；**风格仅在用户要求时写**，默认不写。无资产时，**主体档案/场景锚点写完整版**（角色外观、场景细节，作为模型认知来源）。
2. **【资产说明】**：按资产情况——**有资产** → 写"使用用户提供的 @图片N 资产"，并说明 @图片N 对应哪个主体/场景；**无资产** → 写**完整主体档案 + 场景锚点**（如需先成图，再附 T2I 提示词：主体资产 + 场景资产）。
3. **【视频提示词】**：严格套用统一模板的单条提示词（可直接整块复制），​**纯画面描述**；有资产时镜头正文用 `@图片N 主体短名` 引用。
4. 文末标注当前总字数，确保 ≤4000。

统一模板（**单一完整可复制块**——把总时长、主体档案、场景锚点、音乐、镜头全部并在一起，用户整块复制即可；音乐行默认配 BGM，用户明确不要时改"不要生成任何背景音乐，只生成对应音效"）：

```

【主体】<有图：@图片1 主体1、@图片2 主体2（声明对应）；无图：写完整外观档案>
- 主体1「<短名>」：<无图写完整外观：年龄/发型/五官/服装/道具；有图只写短名>
- 主体2「<短名>」：<同上>

【场景】<有图：@图片N 场景；无图：写完整场景锚点>
- 场景1「<短名>」：<无图写完整：地点/时间/光线色调/天气/空间布局；有图只写短名>

主体：<短名 或 @图片N 主体短名>
场景：<场景短名>

镜头2 ｜ <t1–t2>s ｜ <同上结构>
…（直到末镜，末镜结束时间 = 总时长）
```

> 说明：**主体档案/场景锚点已并入本块**（模型认知来源，无图时必须完整；有图则从简并 @ 引用），叙事规划、镜头数理由、节奏骨架等**设计说明**仍写在【脚本总览】单独呈现，不进提示词块。

## 硬约束（必须遵守）

1. **先确认资产情况，决定写法**：用户已有图片/视频资产 → **分镜正文用 `@图片N 主体短名` 显式引用**，不写 T2I 提示词；用户无资产 → **先写完整主体档案/场景锚点**，分镜正文用短名指代（如需资产图再给 T2I，主体干净背景只展示主体；场景展示代表性全貌、排除人物）。**不要默认每次必给 T2I 提示词**。
2. 总时长范围 4-30s，默认推荐 15-30s，上限 30s；各镜时长之和 = 总时长。时长未明确时先向用户确认或给出推荐。
3. 镜头数完全由故事和节奏决定，无固定档位、无数量上限；每镜时长按镜头类型给（特写/快切 1-3s，中景/叙事 3-5s，全景/建立 5-7s），30s 通常落在 8-14 镜。
4. 视频提示词严格套用统一模板，音乐行默认配 BGM：`音乐：根据画面氛围生成匹配的背景音乐与对应音效`；仅当用户明确不要 BGM 时改为"不要生成任何背景音乐，只生成对应音效"。
5. 一致性：有资产 → 分镜正文用 `@图片N 主体短名` 引用；无资产 → 用短名 + 本镜变化点（外观由第4步完整档案定义）。两种情况都不逐字复述固定外观。
6. 镜头正文**只描述画面**：不写音效、不写剧情作用、不写意图解释。
7. 每镜是视频提示词不是图片提示词：含强动词、镜头运动、时间内变化三要素。
8. 输出总字数 ≤ 4000 字。
9. **违禁词自动替换**：输出提示词时若出现违禁词，**必须自动替换为相近的中性词**，保证最终提示词不含任何违禁词。违禁词分三类：**①血腥暴力类**（血液飞溅/喷血/鲜血淋漓/血池/血祭/斩头血/内脏出血/血腥场面、血债/血洗（具象化暴力）、分尸/碎尸/斩首/砍头/挖眼/掏心/剥皮/凌迟/虐杀/酷刑/断肢/爆头/穿刺/撕咬（含肢体伤害具体动作）、屠杀/灭门/焚尸/垂尸/尸横遍野/血肉模糊/骨裂/脑浆/内脏外露/残肢断臂）；**②低俗类**（全裸/半裸/袒胸露背（过度）/裸露（低俗化）/露骨/一丝不挂/裸体、性感暗示/衣不蔽体（非剧情必要的低俗化）、色情挑逗性裸露/低俗姿势/暴露隐私部位/酥胸半露（过度）/艳舞/低俗互动/性挑逗/裸露祭祀（无合理剧情支撑））；**③色情与性暗示类（极度违规）**（色情/淫秽/卖淫/嫖娼/性交易/一夜情/通奸/乱伦/恋童/兽交、约炮/床上戏（低俗化））。中性替换示例：断肢→跌倒受伤、血流→泛红、裸露→衣衫不整、性挑逗→眼神交流。详见 `references/templates.md` 违禁词速查表。
