## 镜头数决策速查

**镜头数是排完故事节奏、给每镜选好类型之后算出来的结果，不是先定的指标。**

排镜四步：① 列故事节拍 → ② 每个节拍选镜头类型（特写/中景/全景）→ ③ 按类型给时长 → ④ 加总，校准到目标总时长。

| 镜头类型 | 时长 | 用在什么节拍 |
| - | - | - |
| 特写 / 快节奏 | 2-3s | 情绪爆点、关键细节、打斗中的单个动作、快剪组 |
| 中景 / 叙事 | 3-4s | 推进情节的主力镜头，一镜内完成 2 个递进动作 |
| 全景 / 固定镜头 / 长镜头 | 5-7s | 开场交代环境与主体、场景切换后的重新建立、结尾收束 |

**量级参考**（校准用，不是配额）：30s 通常 8-14 镜、均值 2-4s；20s 通常 6-12 镜。全景建立镜多则镜头数偏少，特写快剪多则偏多，都正常。

**典型 30s 节奏骨架**：全景建立(5-7s) → 中景叙事(3-5s)×2-3 → 特写快剪组(1-3s)×3-4 → 中景/近景过渡(3-4s) → 全景收尾(3-6s)。

**该合并的信号**（出现即合并成一镜）：

- 相邻两镜同一场景、同一主体、只是景别不同 → 用推近/拉远一镜完成。
- 相邻两镜只是动作的前半段与后半段 → 用跟拍一镜走完。
- 某镜只为"给个反应镜头"而存在，且不带新信息 → 并入前一镜末尾的表情变化。

**该切的信号**（有其一才切）：
换空间、换时间、换主体视角、换信息层级（如从人切到人所看见的东西）、情绪断点（突变、打断、揭示）。

## 风格 / 运镜 / 光线词库速查

按需取词，全片**统一选用**，不要混搭风格。

### 风格基调

电影感 / 写实质感 / 动漫番剧 / 3D 渲染 / 赛博朋克 / 国风水墨 / 武侠 / 悬疑惊悚 / 热血战斗 / 温情治愈 / 广告大片 / 胶片颗粒 / 暗黑哥特 / 霓虹夜景 / 复古港风

### 景别

大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 / 过肩 / POV 主观

### 镜头运动（明示方向与速度；长镜头写出阶段变化）

缓慢推近(push-in) / 急速推近(fast push-in) / 拉远(dolly out) / 上摇·下摇(tilt) / 横移(truck) / 升降(pedestal) / 跟拍(follow) / 环绕(orbit) / 手持轻晃·剧烈晃动 / 镜头震动 / 甩镜(whip pan) / 慢动作(slow-mo) / 变焦(zoom) / 一镜内复合运镜（如"先低角度缓推，至中段上摇至全景"）

### 光线 / 色调

暖黄夕照 / 冷月微光 / 高反差硬光 / 柔光散射 / 逆光剪影 / 丁达尔光束 / 霓虹彩光 / 顶光 / 边缘光(rim light) / 色温由暖转冷 / 明暗交替闪烁

### 环境动态（视频灵魂，每镜尽量加一项）

衣摆飘动 / 发丝乱舞 / 尘土飞扬 / 落叶飘落 / 雨丝斜飞 / 烟雾升腾 / 影子拉长 / 水面涟漪 / 火星迸溅 / 旗帜翻卷 / 光斑流动 / 呼吸起伏 / 瞳孔收缩 / 夜雾漫开

### 情绪的可见写法（替代"剧情说明"）

情绪不写解释，只写能拍到的东西：

- 紧张 → 攥紧拳头、喉结滚动、瞳孔收缩、下颌绷紧、指节发白
- 犹豫 → 抬手又放下、脚步停顿半步、目光游移
- 释然 → 肩膀垮下、长长吐气使胸口起伏、眉头舒展
- 愤怒 → 额角青筋绷起、鼻翼张合、下巴前顶
- 疲惫 → 步伐拖沓、扶墙撑住身体、眼皮下垂

❌「他内心充满恐惧，象征着命运的转折」　✅「他后退半步、指节攥得发白，喉结上下滚动」

## 违禁词速查表（命中即自动替换为相近中性词，最终提示词不得含违禁词）

### ① 血腥暴力类（重点屏蔽）

**血液相关**：血液飞溅、喷血、鲜血淋漓、血池、血祭、斩头血、内脏出血、血腥场面
**具象化暴力**：血债、血洗（用于具象化暴力场景时）
**伤害动作（含肢体伤害的具体动作）**：分尸、碎尸、斩首、砍头、挖眼、掏心、剥皮、凌迟、虐杀、酷刑、断肢、爆头、穿刺、撕咬
**其他暴力**：屠杀、灭门、焚尸、垂尸、尸横遍野、血肉模糊、骨裂、脑浆、内脏外露、残肢断臂

### ② 低俗类（重点屏蔽）

**直接裸露**：全裸、半裸、袒胸露背（过度）、裸露（低俗化）、露骨、一丝不挂、裸体
**情色暗示**：性感暗示、衣不蔽体（非剧情必要的低俗化描述）
**违规场景**：色情挑逗性裸露、低俗姿势、暴露隐私部位、酥胸半露（过度）、艳舞、低俗互动、性挑逗、裸露祭祀（无合理剧情支撑的裸露）

### ③ 色情与性暗示类（极度违规）

**核心违规**：色情、淫秽、卖淫、嫖娼、性交易、一夜情、通奸
**绝对违规（不可出现）**：乱伦、恋童、兽交
**暗示类**：约炮、床上戏（低俗化）
