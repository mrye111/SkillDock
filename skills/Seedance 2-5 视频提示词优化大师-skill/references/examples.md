## 一、写实 / 纪实 / 真人感 `[写实] [纪实] [口播] [宠物] [手部细节]`

### 案例 A：陶艺师（15s 纪录片质感）

**参考写法**：真实摄影语言（自然窗光/手持/浅景深/皮肤纹理），主动保留不完美细节，负向排除 AI 感。

```
一个 15 秒的超真实纪录片风格人物视频，用全画幅电影机和 50mm 镜头拍摄。
自然下午窗光，轻微手持，浅景深，没有美颜，没有过度调色。
一位年长的女性陶艺师独自在安静的工作室里制作陶碗。她有银色头发，松松地扎在脑后；
脸上有真实皱纹，手指略干，指甲缝里有陶泥。她穿着褪色亚麻衬衫和沾满陶泥的围裙。
[0s-6s] 特写她的双手在拉坯机上塑造湿润陶泥。陶泥表面不完全平整，有水分和细微纹理，
稳定旋转。她的手指自然地按压陶泥。
[6s-11s] 摄影机缓慢上移到她的脸。她专注地看着陶泥，表情安静，眨眼自然。
能看到真实皮肤纹理、细纹、毛孔和轻微面部不对称。
[11s-15s] 她停顿一下，用手腕背面轻轻擦额头，然后重新看向陶泥，露出很淡的微笑。
避免 AI 式油亮皮肤、过度磨皮、完美对称脸、橡胶手、错误手指、虚假的陶泥物理。
```

**参考写法**：体育转播×电影广告的混合风格，锁定场地/队服/人物数量稳定，时间戳分四段。

```

一支穿蓝色队服的女子排球队完成一次接发球组织进攻。保持队服颜色、球场布局和人物数量稳定。
[0s-4s] 从接发球队伍后方拍摄广角镜头。对方球员跳发球，排球快速越过球网。
[4s-8s] 蓝队自由人向前鱼跃接球，身体在木地板上自然滑动，手臂准确垫球。排球向上形成清晰弧线。
[8s-12s] 二传手跑到球下方，做出标准双手上手传球。摄影机横向跟随她移动，队友开始快速跑位。

保持正确排球场地、真实人体力学、准确球的运动轨迹、稳定队服。
不要多出手臂，不要让球漂浮，不要让球网或场地线变形。

## 二、广告 / 带货 / 营销 `[广告] [带货] [口播] [电商] [产品特写]`

### 案例 E：茶叶电商带货（30s 竖屏 9:16 口播带货）

**参考写法**：真实源头发货质感（茶仓实拍/轻微手持/非棚拍），动作连续（手压饼→拆包→捏条索→注水→出汤），多镜头硬切、每段标时间戳+台词/字幕参考，运镜不炫技。

```
视频风格：竖屏 9:16，真实电商带货短视频，山里茶仓源头直拍风格。
画面质感朴素、自然、轻微手持感，像手机或小型相机在茶仓和木桌边实拍。
不要电影大片感，不要棚拍广告感，不要过度美颜，不要虚假豪华茶室。
保留原片的真实茶农/源头老板口播气质：节奏快但不浮夸，动作实在，手部细节清楚。
运镜说明：多镜头剪辑逻辑主要镜头类型：手部产品特写、人物中景口播、桌面俯拍、
极近条索特写、冲泡动作近景、茶汤特写。镜头要明确服务卖点：包装质感、年份库存、
拆包状态、干茶条索、沸水高冲、汤色。转场以原片式硬切为主，不要花哨转场，不要运镜炫技。
每个动作必须连续：手压茶饼、手翻包材、手拆包装、手捏条索、壶嘴注水、盖碗出汤，
动作方向和物体位置不能跳乱。
[0-2s] 极近手部特写。镜头对准木桌上叠放的笋壳/荷叶包圆形茶饼，
一只手从画面上方按在茶饼表面，轻轻压出包装纹理。画面要能看清麻绳、干燥叶壳、老包浆质感。
台词/字幕参考：2018年冰岛甜
[2-4s] 镜头硬切到包装特写，茶饼叠放在木桌上，镜头略微下压或微推近，
突出笋壳/荷叶包扎的圆形轮廓。画面不要出现现代塑料包装。台词/字幕参考：荷叶包的

背后有竹篮、纸箱和山林绿色背景。她低头整理茶饼，同时对镜头讲解。台词/字幕参考：今年收茶的老板少
[6-8s] 继续人物中景，镜头保持稳定，老板手指着桌上的茶饼，强调年份卖点。
桌面茶饼排列整齐，人物表情认真朴实。台词/字幕参考：这批存了6年的冰岛甜
[8-11s] 硬切到手部近景。双手把叠放的茶饼从一侧扶正，手指压住包装边缘，动作像在清点库存。
镜头从正上方略微俯拍，木桌纹理明显。台词/字幕参考：还有不到400饼、出了换钱收春茶
[11-14s] 手部俯拍近景。双手慢慢拆开外层荷叶/笋壳，从边缘向外翻开包材，
露出里面深色圆茶饼。动作要清楚：左手按住茶饼，右手掀开包材，不要瞬间自动展开。
台词/字幕参考：荷叶包的、存了6年
[14-16s] 茶饼露出特写。镜头停在打开后的茶饼上，边缘干叶和茶饼压纹清楚，

台词/字幕参考：承接"高冲"，突出汤色金黄通透

## 三、打斗 / 动作 / 冒险 `[打斗] [动作] [冒险] [奇幻] [武侠] [近身搏斗]`
