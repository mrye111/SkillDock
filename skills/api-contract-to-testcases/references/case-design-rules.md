# 接口测试用例设计规则

## 1. 设计边界

- 只基于接口契约文档生成接口测试用例。
- 不补充契约中未声明的字段、默认值、状态码、数据库规则、审批规则。
- 契约不明确的部分，转入待确认项，不直接写入正式用例。

## 2. 允许使用的设计方法

### 2.1 等价类 + 边界值

适用范围：

- 单参数校验
- 字段必填/非必填
- 长度范围
- 数值范围
- 枚举值
- 日期格式
- 手机号/邮箱/身份证等格式
- 文件大小、类型

输出要求：

- 至少包含 1 条合法等价类
- 至少包含 1 条非法等价类
- 若契约存在边界约束，补充最小值、最大值、越界值

### 2.2 场景法

适用范围：

- 前后置依赖
- 资源创建后再查询/绑定/审核
- 注册 -> 登录 -> 业务提交
- 小区 -> 楼栋 -> 单元 -> 房屋 -> 业主入住

输出要求：

- 覆盖主流程
- 覆盖关键依赖缺失场景

### 2.3 错误推测

适用范围：

- 鉴权缺失
- token 错误
- 请求头错误
- 重复提交
- 上游资源不存在
- 文件类型不符
- 数据类型不符

### 2.4 状态流转

适用范围：

- 审核接口
- 入住、绑定、发布、上下架
- 已处理/未处理、已审核/未审核、已通过/未通过等状态流转

输出要求：

- 至少覆盖一个合法流转
- 至少覆盖一个非法流转或重复流转

## 3. 覆盖要求

每个接口默认至少覆盖以下场景：

1. 1 条正向主场景
2. 1 条异常场景
3. 1 条单参数等价类或边界值场景

若接口存在以下特征，则必须追加相应场景：

- 有鉴权：补充缺失头、错误 token、错误版本头
- 有枚举：补充非法枚举值
- 有长度/范围：补充边界值
- 有状态流转：补充重复操作或非法状态转换
- 有资源依赖：补充上游资源不存在
- 有文件上传：补充文件类型和大小异常

## 4. 待确认项触发条件

以下情况不得直接进入正式用例：

- 响应 `code`/`msg` 未定义但要求精确断言
- 文档只说“需要鉴权”但未说明规则
- 文档出现“审核”“发布”“绑定”但未给状态约束
- 字段有描述但无明确长度/范围/格式
- 登录返回 token 字段位置不明确
- 业务链依赖关系未明确
