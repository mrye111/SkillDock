# 技巧库（蒸馏自七猫专栏「拒稿到签约：过稿经验分享」）

## 一、编辑拒稿模板对照表（诊断模式主表）

来源：七猫女频编辑"满星"亲述。用户贴稿时逐条比对，命中即引用原文证据。

### 1. 文笔类
| 编辑评语 | 真实含义 | 改法 |
|---|---|---|
| 文笔有待提升 | 直白叙述、无画面感 | 删"她哭得很伤心"式陈述，改动作+神态细节（"她蜷缩在墙角，指甲掐进掌心，喉咙里溢出压抑的呜咽"）；删冗余描写；避免视角频繁切换 |
| 细节刻画力度稍弱 | 场景/人物停留在表面 | 加让读者身临其境的感官细节 |
| 复杂情感不够细腻 | 角色塑造浮于表面 | 关键情节深入心理活动，用行为细节传递情绪（"蜷缩墙角"暗示绝望） |

### 2. 开篇类
| 编辑评语 | 真实含义 | 改法 |
|---|---|---|
| 切入点缺乏吸引力、代入感弱 | 平铺直叙背景开场、日常流水 | 用冲突/悬念开场，简明扼要亮出剧情设定看点 |
| 背景铺垫过长 | 大段解释世界观/家庭关系 | 干脆利落写剧情，让剧情自己解释发生了什么 |
| 出场人物过多 | 开篇人物人名太多 | 戏份集中在含主角 3–5 人，减少阅读障碍 |

### 3. 叙事类
| 编辑评语 | 真实含义 | 改法 |
|---|---|---|
| 剧情节奏拖沓 | 无关描写多、矛盾堆砌 | 围绕主要矛盾展开，砍掉一切与主线无关的内容 |
| 缺少钩子和悬念 | 没有追读理由 | 主线大钩子（离婚文：什么时候离；马甲文：什么时候掉马）+ 章尾卡点（反转/冲突/暗示） |
| 视角混乱 | 多视角乱跳 | 开篇锁定主角单一视角，让读者快速代入 |
| 主角存在感弱 | 配角戏太多 | 删配角塑造，把戏份还给主角 |
| 前后画风不统一 | 类型中途跑偏 | 追妻火葬场就好好火葬场，别半路变末世 |

### 4. 人物类
| 编辑评语 | 真实含义 | 改法 |
|---|---|---|
| 人物不够立体 | 行为片面、模式单一 | 补人设四要素（见下） |
| 人物脱离现实 | 行为逻辑前后矛盾 | 给"不符合人设的行为"一个令人信服的解释，或者删掉 |
| 主角主观能动性弱 | 主角被剧情推着走 | 让主角主动触发剧情、推动事件 |

### 5. 主线类
| 编辑评语 | 真实含义 | 改法 |
|---|---|---|
| 主线不清晰 | 看完不知道主角在干嘛 | 交代清三样：主角的目标、障碍、需要做什么 |
| 主线期待感弱 | 核心钩子抛完后没接新的 | 旧钩子回收前必须埋新主线钩子 |

### 6. 其他高频退稿理由（社区补充）
- **模板拒/综合质量差**：基本功不够，先扫榜学习沉淀，别急着改。
- **缺乏爽点**：主角长期无成长无收获。爽点 = 正向反馈（升级、报仇、认可、目标达成）。
- **缺乏代入感**：没爽点 / 上帝视角写爽事 / 人设让人不想代入（圣母、舔狗）。高潮处切主角主视角 + 情绪 + 动作。
- **节奏缓慢流水账**：只写与当前重点有关的事。本章重点是"下楼买泡面"，就别写几点起床、电梯、牛奶打折。
- **没有伏笔期待感**：平铺直叙不挖坑。

## 二、黄金一章 / 开篇技巧

### 硬性数据（玄弈，直投签约作者）
- 前 200 字无冲突 → 80% 被毙；前 600 字无冲突 → 90% 签约失败。
- 前 6000 字主线不清 → 80% 签约评估不通过。
- 三章无反转 → 80% 签约失败。
- 开篇 2000 字无大悬念、每章无钩子 → 大概率拒。
- 金手指最好第一章就出，放第二章已经很慢。第一章就要告诉读者"爽点快来了"。

### 对话式开头三型（笔炼成神）
1. 悬念型："xx，你不是被毒死了？"
2. 劲爆型：制造歧义/冲击的一句对话开场。
3. 仇恨型："xx 意图杀兄弑师……按门规打成废人，逐出师门！"
作用：跳过背景交代，直接强化代入感（海明威冰山理论：只露一角，其余让读者探索）。

### 三幕式章节（开端-发展-反转）
- 开端：主角直接陷入生死级危机（参考《十日终焉》），制造"他怎么破局"的好奇。
- 发展：金手指出现（系统/神器/功法/血脉觉醒），主角反杀，压抑情绪释放 = 爽感。
- 反转/章尾挖坑：反派后有幕后推手 / 新一轮追杀 / 金手指新功能 / 好友背刺——设计读者想不到的画面。

### 视角与流畅度（QQ你让我火吧）
- 同一段剧情，主角视角 vs 上帝视角对比：
  - × 上帝视角："昏暗的房间里，一个男人把南笙按在沙发上……"
  - √ 主角视角："'好痒……'南笙迷迷糊糊苏醒，感觉腿上一阵瘙痒……"
- 代入感强的小说都从主角视角展开；上帝视角让读者找不到重点、分不清主角。
- 流畅度靠语感（多看多写）；自检语病；用最少的文字描绘最真实的画面，求"准确"不贪多。

### 亮点 · 期待感 · 卖点
- **亮点 = 新鲜感**（"阿凡达效应"）：题材创新难，就做开篇微创新（别人写下药，你写灌酒——同状态新壳）。
- **期待感 = 信息差**：读者知道、角色不知道，读者就会喊"别认！他在骗你！"。变体：悬疑型（柯南：凶手是谁）、复仇型（斗破三年之约：必看打脸）。
- **卖点 = 读者一直追的那个点**：风格化标签——热血（斗破）、暧昧（我的绝色老板娘）、诡异抽象（道诡异仙）。新人做好亮点+期待感即可，卖点自然浮现。
- **设定夹在剧情里**：男神出场时顺带交代背景，就是介绍设定；没有设定剧情推不动，但第一章绝不集中抛设定。

## 三、扫榜方法（邪修高效版，高数！不共戴天！）

- 无效扫榜 = 每句话都做阅读理解。有效扫榜 = 只扫每本书前三章，问一个问题：**它靠什么把我留下来的？** 那个点就是期待点。
- 体会到前三章精髓后，有意识地把别人的期待点化用成自己的。
- 至少挑 5 本印象最深、最想看的，继续往后扫：看期待点如何在前十章回收 + 给出小爆点（最爱那本可看到 30 万字）。
- 先出发再捡装备：别等"准备完美"才动笔。
- 文笔速成：写完一章，对照大神同类型章节，看人家遣词造句和行文结构，把啰嗦处照着改。
- 新人大纲多为无效大纲（只有"主角要做什么"，无起承转合、无大小框架）——要么学大神的大纲法，要么先不写，但要有主线锚点。

## 四、全流程框架（安澜瀧王整合版）

### 战略：动笔前三问
1. 我的故事讲什么？（一句话概括主线）
2. 写给谁看？（目标读者画像）
3. 市场上有没有类似成功作品？（找对标）

题材微创新四招：职业置换 / 关系错位 / 背景迁移 / 热梗叠加（有主次）。

### 包装三件套（决定点击率）
- 书名：带情绪、有看点、有关键词；忌文艺含蓄无信息量（×《星辰之下》）；收集热门关键词组合，避生僻字。
- 简介三段式：①背景（身份+核心处境）②冲突（核心矛盾+情绪爆发）③悬念（埋钩子）。段落要短，手机阅读优先。
- 封面：风格统一、色彩鲜明人物突出、标题大字醒目。

### 人物
- 人设四要素：基础设定（年龄/外貌/身份/性格）、个性化标签（口头禅、小习惯）、反差萌（高冷霸总怕打雷）、人物弧光（懦弱→强大）。
- 逆推法：先定行为，再问"他为什么这么做"（刚正不阿 ← 出身将门）。
- 配角也要有动机，避免纯工具人；不能突然降智。

### 情节与节奏
- 小剧情单元：目标 → 行动 → 阻碍 → 反转。
- 大剧情链：起因 → 发展 → 转折 → 高潮 → 结局。
- 期待感五法：设悬念 / 造冲突 / 控制信息释放（剥洋葱）/ 高潮节奏（三章一小爆、十章一大爆）/ 情感连接（让读者心疼主角）。
- 防拖沓 8 技巧：背景拆散融入剧情；同一事不重复叙述；章尾留钩子；心理描写用动作替代；删无意义外貌环境描写；对话要有信息量；支线服务主线；用逻辑时间线防卡文。
- 伏笔三原则：有伏必应、记录在案、自然融入。

### 大纲六件套
1. 世界背景（年代/规则/场景）
2. 类型与元素（古言重生/追妻火葬场/读心术）
3. 人物设定（小传+关系图）
4. 故事亮点（3–5 个核心爆点）
5. 故事线索（主线+支线+暗线）
6. 阶段梗概（每 10 万字一阶段，标高潮点）
套经典框架（赘婿逆袭、战神归来）再做微创新。

### 投稿与心态
- 红线：涉政、涉军、抄袭、导向不正、乱码投稿、AI 代笔。
- 拒稿三因：故事不好看 / 平台不对路 / 讲述方式不对 → 分析原因 → 学干货 → 改稿重投。
- 与编辑沟通：×"在吗？怎么改？" √"编辑您好，我是《XXX》作者，附上修改后的大纲和开头，请您指教。"
- 断更 = 弃书；固定时间固定字数（如日更 4000）培养读者追读习惯。
- 灵魂三问（卡文/跑偏时自问）：主角终极目标是什么？驱动 TA 的核心动机是什么？这本书最独特的卖点是什么？
