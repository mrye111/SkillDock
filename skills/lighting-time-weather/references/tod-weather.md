# 室外时段与天气

## 时段（Time of Day, ToD）

仅使用：日出、白天、黄金时刻、日落、蓝调时刻、夜晚。

- **日出 / 日落：** 都是低太阳高度角；方向重要时必须指定。日出与黄金时刻不是同一个状态。
- **日出 / 日落成组连续性：** 同一底图要生成连续时段组时，锁定一条太阳轨迹（sun path）。日出与日落必须落在画面相反侧：日出在左侧/左侧画外，则日落在右侧/右侧画外；反之亦然。用户明确指定方位时优先服从用户指定。
- **白天：** 定向阳光加天空补光（sky fill）。阴影必须由原图已有遮挡物产生。
- **黄金时刻：** 必须判明它在日出后还是日落前。
- **蓝调时刻：** 没有直射阳光；低强度冷色天空光可与有动机的实用光源共存。
- **夜晚：** 只保留交代场景所需的亮度。只能依靠实用光、月光/天空光、入口光或合理反射光；不得平均提亮整张画面。

用户未指定方向时，可由构图保守推断；指定时必须服从指定方向。

## 时段 × 天气兼容门

先建立天气，再决定该天气下可保留多少时段特征；不能把两个各自正确的模块机械叠加。

- 厚阴天、浓雾、稳定降雨：取消清晰、长而硬的直射日照影；若仍需方向性，只保留受云层或空气削弱后的宽软明暗关系。
- 晴天与黄金时刻：可有低角度定向日光；若采用浓雾、暴雨或厚云，日光必须相应减弱、扩散或退出。
- 蓝调时刻：无直射太阳；只允许冷色天空余光与有动机的实用光共存。
- 夜晚：不保留白天日照方向、金色天光或干燥晴日阴影；能见度、湿润和反射仅由已有夜间环境/实用光支持。
- 雪、雾、雨只是环境状态，不自动规定时段；它们必须服从该时段可解释的天空、太阳或实用光。

若用户明确要求矛盾组合，说明冲突并提供最接近的物理可行版本；不要以风格滤镜硬凑。

## 成组变体的母版连续性

当夜景、浓雾、重阴影或失焦底图缺少其他时段必须可见的信息时，允许一次有限、合理的场景补全。先获得用户认可的补全母版；随后所有 ToD / 天气变体都以同一母版为基础，锁定补全部分的物体、窗口、建筑、植被、几何与位置。后续版本只改变光照、空气与表面状态，不得每次重新补出不同内容。

## 晴天与阴天

- **晴天：** 是定向直射光加天空补光，不是整体加黄。树冠、建筑或地形可以产生阴影，但不得仅为了表现太阳而虚构花纹。
- **阴天：** 是大面积、偏冷的散射天空光，不是去饱和。保留明度结构：开阔天空/外露面 > 中间平面 > 遮蔽的负补光区（negative fill）。以空气透视保留空间层次。

## 雨

把天空/光线、表面湿润、雨的可见性和反射联系起来。雨主要在逆光、侧逆光、深色背景或局部光池中可见；不得在全画面均匀铺同样的雨丝。

湿地反射取决于观察角度、光源、材质与积水。用表面变化打断反射，不要让每个地面都像镜子。只有场景条件支持时才使用米氏散射（Mie scattering）、消光（extinction）或体积雾；不得把次表面散射（subsurface scattering）作为通用雨效。

无人工光的雨夜，应通过已有天空或真实环境光保持可读性；不得为了让雨可见而新增路灯、车辆、窗光或光束。

## 雾

雾是由镜头距离决定的体积：前景更清楚，中景更柔，远景逐步被遮蔽。等深度的画面左右区域应受到相近的雾影响。不要把雾集中到消失点或画面中心。可选：轻雾 / 中雾 / 浓雾 / 极浓雾。

## 雪

独立指定以下四项：

1. 地面积雪：无 / 薄湿新雪 / 中等 / 深雪。
2. 降雪：无 / 稀疏 / 中等 / 大雪。
3. 风：无 / 轻微 / 明确方向。
4. 复杂植被附雪：无 / 稀疏点缀 / 有限。

积雪受天空暴露度、朝向、遮挡、风、材质、微地形、融化与扰动共同影响。宽阔且稳定的朝上表面可接受低频、不均匀、厚薄变化的雪；保留边缘、排水、足迹、道路磨损与断裂。

复杂叶片、细枝、灌木和树冠默认无雪或仅有不连续的顶部稀疏点缀。不得给整棵树均匀铺白、描白边、增粗或锐化。大雪不等于厚积雪。

可通过冷色温、曝光层级、大气、远方环境线索及可选降雪建立雪景氛围。大光圈与浅景深是有意的镜头选择，不是雪景默认效果。
