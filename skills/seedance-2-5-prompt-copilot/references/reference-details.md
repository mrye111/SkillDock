## 00-index — 参考索引

选择规则：按失败条件选择加载哪个参考文件。

模式准入规则：保留模式需满足 6 个条件（独特用户任务、官方/可检查高信号支持、特定参考包或提示词更改、可见验收测试、最小修复动作、无未验证运行时声明）。

证据层级：O（官方）、F（第一方）、P（流行可复现）、D（领域标准）、S（二级）。

## 01-capabilities-and-boundaries — 能力与边界

官方模型方向：Seedance 2.5 支持最多 30 秒叙事、精确参考控制、更流畅一致的运动、更真实的视觉效果、更广泛的音视频编辑、白模控制、绿幕编辑、专业镜头运动和表演调度、两次可选扩展。

第一方产品面：Dreamina 描述的多模态大包、R2V、最多 50 个参考等，仅作为产品面声明，实际参数可能不同。

运行时真相：必须通过实时 TapNow 目录确认模型 ID、可用性、模式、输入类型、参考上限、编辑控制、参数、价格和安全约束。

生产边界：生成广告不能证明产品声明；生成 UI 不能替代真实功能捕获；生成游戏/电影画面不是可玩功能证明；白模/平面图仅为概念可视化；生成地图/地点/车辆/野生动物/历史/医学/科学/新闻类场景需要来源所有权和披露。

## 02-reference-orchestration — 参考编排

参考角色地图：P0/P1/P2 优先级表。

参考覆盖：构建完整兼容参考覆盖，包含每个必须保留事实的来源。

角色特定包：
- 角色/数字人：干净面部、全身服装、表演、批准语音、场景、同意。
- 产品/美食：主角几何/SKU、替代视角、批准操作、包装文案、手部动作、品牌风格。
- 故事/短剧：演员手册、重复场景、故事板、对白、风格锚、起止状态。
- 空间/车辆：平面图/白模、材质板、真实连接器、产品真相、镜头路径、安全披露。

故事板与动画：将面板映射到镜头和时间区间；箭头、注释变为指令；不默认裁剪。

动作参考：明确控制全身动作、手部交互、姿势序列、镜头路径、剪辑节奏或仅 timing。

白模控制：保留几何、标记、动作路径、镜头路径；仅改变表面、材质、光线和布景。

绿幕控制：用于干净转移身体动作、目标环境不同、需要控制遮挡、表演者和镜头需要分开权威。定义地板接触、比例、方向、进出、光线整合、阴影。

音频参考：分离精确复制信号、音色、对白/歌词、节拍、音效纹理、环境音、观众专属音乐。

冲突协议：对每个冲突，声明冲突特征、按层级提议的权威、可见后果、所需表单确认。

## 03-first-last-frame — 首末帧模式

适用场景：精确前后状态、姿势落位、产品组装/揭示、可控变换、匹配动作、必须精确起止的单镜头。

锚点契约：首帧拥有开场姿势、物体状态、构图、镜头、光线；末帧拥有终态姿势、物体状态、构图、镜头、光线。它们不自动拥有目标动作或来源身份。

插值计划：建立首帧 → 触发因果动作 → 经过可观察中间态 → 逐步缩小差异 → 到达末帧前 → 停留足够时间。

常见失败：突然跳跃、末帧未命中、身份漂移、物体变形、镜头不匹配、装饰性过渡。

审查：首帧是否精确开场？每个差异是否由动作解释？共享特征是否稳定？镜头是否收敛？最终帧是否到达并停留？

## 10-prompt-architecture — 提示词架构

参考绑定：命名资产和精确控制层级。区分身份与姿势、产品几何与风格、场景几何与材质、镜头路径与编舞等。

事件语法：起始状态 → 触发/意图 → 可观察动作 → 接触/变化 → 可见可听响应 → 结束状态。

镜头与剪辑：一个区间一个主导镜头意图；剪辑必须引入新信息；镜头运动替代小角度变化；匹配剪辑需定义形状、方向、颜色、声音或构图。

镜头表达：景别/构图、运动类型、主体关系、有意义的速度、起止构图。不要堆叠过多不相关的运动。

对白与表演：保留精确文字、语言、标点、说话人；指定画内/画外/旁白；同步视线、表情、手势、呼吸、嘴型。

音频层级：对白/演唱、音色、房间音、物理效果、画内音乐、观众专属配乐、有意沉默。

精确文本和 UI：引用精确文案；命名位置/表面；指定进入和停留时间；确保构图可读；保留本地化和法律措辞；必要时推荐作者叠加层或真实 UI 捕获作为真实层。

否定指令：简短、因果的避免列表（身份/SKU 漂移、额外肢体、布局改变、随机字幕/水印/标志、不支持的声明、破坏最终构图的镜头运动）。不要添加通用质量否定墙。

最终检查：拒绝未绑定参考、未解决冲突、区间间隙/重叠、一个区间包含多个无关事件、精确文案/对白被更改、终态不可观察、事实/商业证明仅来自生成图像、公共限制被伪装为 TapNow 支持。

## 20-story-previs-performance — 故事、预演与表演

短剧/叙事序列：构建戏剧问题、演员关系图、重复场景道具手册、节拍顺序、精确对白、每次剪辑的连续性状态、最终情感/故事图像。

故事板/动画转视频：故事板拥有镜头顺序、舞台和构图；身份来源拥有重复角色；风格来源仅拥有渲染；占位音频仅拥有节奏。

白模动作预演：保留已解决的几何、比例、标记、动作路径、镜头路径、遮挡和接触。

格斗/运动/特技：意图与恢复台账（预期 → 路径与接触 → 力量与反应 → 恢复与最终标记 → 镜头安全）。

一镜到底穿越：定义入口和目的地、逐门槛路线、演员/物体交接、遮挡点、镜头高度/净空/速度变化、光线和音频连续性、最终揭示。

音乐/舞蹈/表演电影：音频优先地图；绑定表演者身份与编舞和音频分开；保留精确歌词和语言；口型同步时隔离声乐权威。

多人/乐队：每个人映射到身份、舞台标记、服装、乐器、声乐角色、互动伙伴、拥有镜头。不要在快切中合并身份或乐器。

游戏过场/技能揭示：角色/IP 真相、游戏幻想、预期、效果起源和路径、接触和状态变化、恢复/反击窗口、场景几何、最终玩家承诺。标注为电影/概念。

匹配剪辑/节拍蒙太奇：跨剪辑选择一个不变量（中心物体、运动方向、剪影、颜色、声音、构图）。

长序列角色连续性：追踪面部/身体/服装、携带道具、位置和屏幕方向、情绪状态、知识状态、受伤/污垢/天气、对白和语音、光线/时间。

## 30-commercial-growth — 商业与增长

商业真实闸门：记录批准的产品/SKU、功能、精确优惠/价格/声明/CTA/法律文案、真实 UI、版权、披露、目的地和画幅。

UGC/创作者广告：前三秒钩子 → 创作者使用真实产品 → 一个可见证据/反对节拍 → 批准 CTA 和披露。不虚构个人经历、推荐、结果、折扣、稀缺性或物质联系。

电商产品演示：产品真相矩阵（是什么、怎么用、可见的批准结果、为何重要、采取什么行动）。保持几何和标签固定。

电影感产品/品牌片：一个主张、一个视觉隐喻、一个英雄终态。分离产品真相、环境变换、镜头语法、材质/光线、声音身份、精确结尾文案。

时尚与美妆：绑定人才和同意、服装/SKU、材质/颜色/合身、姿势/动作、批准声明、匹配前后条件、CTA。过渡时使用遮挡物。

食品饮料：烹饪状态台账（起始状态 → 接触/热/动作 → 结果状态 → 连续性）。追踪液位、体积、融化、蒸汽、质地、碎屑、装饰。

App/SaaS 广告：用真实 UI 捕获作为功能真相；不要发明 UI。

汽车/高价值产品发布：锁定型号、配置、车身、轮毂、灯光、油漆、内饰、HMI。不暗示安全、自动驾驶、性能或可用性声明。

社交 Hook-Body-Close：Hook 传达价值/好奇心；Body 展示一个证明单元；Close 重复产品/品牌、批准动作和披露。

产品变体测试：每次只改变一个变量（钩子、人设、证明、反对、镜头语法、场景、CTA、画幅）。

商业本地编辑：用于手部接触、标签/标志、产品颜色/材质、背景杂物、表情、CTA 层。

## 31-knowledge-enterprise-localization — 知识、企业与本地化

讲解器：从一个受众问题和一个可观察答案开始。构建批准事实、概念状态、视觉隐喻 vs 字面机制、旁白、屏幕文案、图表/UI/数据真实层。

产品教程：步骤台账（起始状态 → 用户动作 → 系统响应 → 正确终态 → 警告）。

培训：可观察学习目标契约（学习者、培训后动作、条件、成功标准、范围外、批准来源）。

安全/程序：精确产品/版本、先决条件和 PPE、有序步骤、危险和停止条件、可见正确/错误区分、安全终态、合格审查员。

数字人/演示者：同意和使用台账（身份和语音所有者、授权目的、渠道/市场/期限/编辑权、精确脚本、披露要求、撤销路径）。

多语言演示者：每个本地化确认意义和术语、自然措辞、语音权、语速、手势/文化适配、单位/日期/名字/CTA/法律文案、母语审查。

配音：分离翻译脚本、声乐表演、节奏、口型接近度、房间音和混音、原始表演和身份锁定。

字幕与无障碍：作为独立交付物处理（翻译字幕、同语言字幕/SDH、转录、视觉信息的音频描述）。确定性地创作。

企业本地化矩阵：按本地化分列脚本、语音、术语、UI/文案、法律、审查员、状态。

企业/内部沟通：一个批准信息、受众动作、准确产品/流程状态、克制的镜头和风格、干净语音和创作文本、版本日期和所有者。

## 32-factual-regulated — 事实与监管工作

证据台账：声明/场景、来源、日期/版本、证据类别、允许的视觉用途、披露、所有者/审查员。

证据类别：验证当前捕获、档案、授权重建、生成插图、隐喻、未知/未验证。生成输出永远不会升级证据类别。

纪录片/编辑：分离验证素材、采访陈述、档案、作者地图/图表、披露重建、说明性 B-roll。

历史重建：记录已知事实、未知、来源冲突、视觉选择。使用 distinct 插图处理和披露。

医疗/健康：医疗证据台账（声明和来源、人群和适应症、益处、重大风险和限制、批准措辞、字面 vs 说明视觉、合格审查员）。不诊断、保证结果、最小化风险。

药品/器械/监管产品：锁定精确产品/版本、批准适应症、先决条件和 PPE、操作、响应、警告、限制、安全终态。公平呈现重大风险。

科学与数据：来源拥有的定义、单位、日期、比例、因果 vs 相关措辞、不确定性、图表/数据层、专家评审。生成运动仅用于上下文或隐喻。

食品安全/程序：不使用外观作为安全证明。来源精确温度、时间、储存、过敏原、卫生指导。

野生动物：物种真相台账（分类和生命阶段、解剖和比例、运动和行为、栖息地和季节、观察 vs 生成行为、福利/许可/距离、专家/本地审查）。

文化和活态遗产：确认社区所有权、背景、归属、同意、受限元素、利益、本地审查。

新闻类/时事：需要来源日期、地点、状态、捕获类别和披露。不生成可呈现为真实报道的素材。

合成 likeness/推荐：记录同意、身份/语音权、目的、市场、期限、编辑范围和披露。

## 33-spaces-mobility-travel — 空间、移动与旅行

空间台账：空间/楼层、来源、尺寸/比例、邻接关系、固定元素、允许的舞台、状态。

平面图/白模转视频：绑定平面图、白模几何、真实参考摄影、材质和光线板、镜头路径。保留墙壁、开口、门槛、比例、邻接。

房产漫游：逐门槛规划（起始空间和方向、真实连接器、镜头净空和高度、揭示目的、光线和音频连续性、目的地和最终构图）。不要瞬移或发明视图。

建筑/室内概念：生成视频用于体量、材质、光线、体验或设计选项。来源拥有的图纸和模型控制几何。

汽车真相矩阵：市场/型号/配置、车身/轮毂/灯光/油漆、内饰/HMI/选项、功能先决条件/限制。

车辆动作/追逐预演：白模用于路线、标记、速度变化、镜头位置、遮挡和无碰撞规划。标注为预演。

旅行地点真相台账：官方地点和地图来源、季节和捕获日期、当前访问/状态、路线和交通、无障碍、许可/无人机/隐私/野生动物限制、视觉类别、本地/官方审查员。

路线地图/行程：确定性地创作地图。生成片段仅用于说明停留，不验证路线。

文化旅游：使用社区拥有的背景、同意、归属、利益、限制和本地审查。避免刻板印象和受限仪式。

受保护/敏感地点：确认许可、访客影响、隐私、无人机、野生动物、脆弱资源、路线和安全 CTA。

## 40-local-editing-and-repair — 本地编辑与修复

保留矩阵：身份/产品、几何/构图、运动/镜头/剪辑、对白/音频、光线/风格、文案/证据/披露。仅当矩阵可观察后才使用本地编辑。

本地区域编辑契约：源视频和输出版本、空间目标或蒙版描述、进出时间、请求更改、保护周围、遮挡/接触/阴影/反射/音频行为、验收帧或条件。

常见本地编辑：
- 身份/表情：保留身体、服装、镜头、光线、语音、节奏；仅更改命名面部特征。
- 手部/物体接触：定义手、物体、握持/接触点、力度、路径、结果、释放。
- 产品/标签/颜色：绑定精确 SKU 和材质；保留比例、透视、反射、阴影、运动、接触。
- 背景/场景：保留主体边界、运动、镜头、地板接触、光线方向、反射。
- 音频/对白：保留源视觉（除非口型是编辑部分）；锁定精确脚本、说话人、语言、节奏、语音关系、房间音、音乐。
- 本地 VFX：定义效果起源、传播、边界、交互、保护区域、完全消散。

源时间映射：区分源区间和输出区间。

扩展：从真实终态继续（姿势和方向、物体状态和速度、镜头路径和镜头行为、光线和天气、对白/音乐/环境音、未解决动作）。引入一个新节拍，然后稳定。不要重启场景。

失败诊断：
- 参考被忽略 → 无显式角色或优先级 → 添加权威和拥有区间
- 身份漂移 → 竞争风格/角色来源 → 提升身份 P0，降级风格
- 几何漂移 → 表面来源覆盖 blockout → 重新断言平面图/白模
- 故事板混乱 → 未映射到时间 → 添加面板-镜头-区间映射
- 动作模糊 → 多个动词共享一个区间 → 保留一个因果链
- 镜头过载 → 冲突运动 → 保留一个运动或动机剪辑
- 音频不匹配 → 提示在区间外 → 将精确提示移入拥有区间
- 口型同步失败 → 脚本/语音/节奏冲突 → 隔离声乐权威和节奏
- 本地编辑溢出 → 缺少保护区域 → 添加空间和时间边界
- 产品/声明错误 → 生成图像拥有真相 → 恢复批准来源/确定性层
- 文本错误 → 画内生成用作最终文案 → 使用作者叠加层
- 长序列漂移 → 无终态交接 → 每个区间添加连续性状态

可控重试：
1. 记录通过层
2. 命名一个失败的验收标准
3. 识别一个因果指令或参考冲突
4. 更改一个区域、区间或变量
5. 保留模式、包顺序、时长和所有通过层
6. 比较同一审查帧或标准

审查顺序：参考影响和 P0 锁定 → 身份/产品/几何 → 事件顺序和端点 → 镜头和转场 → 对白和音频 → 本地边界和连续性 → 风格和润色 → 文本、证据、版权、披露和交付。

## 99-eval-cases — 评估用例

- 强制性前置表单：即使提供完整故事板和精确对白，第一步仍是 show_form。
- 默认多参考模式：即使无附件也保持多参考推荐，不发明资产。
- 首末帧模式：即使两张附件看似端点，表单仍先提供多参考选项。
- 强制性时间码 Timeline：15 秒必须使用 【0:00-0:03】 到 【0:12-0:15】，无间隙、无重叠。
- 大包处理：28 个混合资产需构建优先级地图，分组，识别重复和冲突，请求批准。
- 故事板和身份：故事板拥有顺序/舞台；干净演员图像拥有身份。
- 白模转移：保留几何、门槛、路线、镜头；仅转移材质、光线、布景。
- 绿幕表演：动作来源仅拥有动作；身份和场景保持分开。
- 商业证明：不虚构经历、推荐、结果、稀缺性或折扣。
- 培训准确性：需要批准的步骤台账和合格审查员。
- 事实重建：分类为披露重建或插图，防止呈现为真实报道。
- 医疗/监管声明：创建证据台账，要求批准措辞和合格审查。
- 本地化：按本地化构建脚本、语音、术语、单位、布局、CTA、法律、审查员。
- 本地区域编辑：创建本地编辑契约和保留矩阵，保护几何、镜头、手部接触、音频、时间线。
- 可控重试：仅更改接触区域/指令，保留模型请求、时长、包顺序和通过层。
- 运行时缺席：交付批准的提示词包并报告运行时差距，不静默回退。
